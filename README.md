# 最速乗換（通学ルート専用）v0.1

単一ファイル `index.html` を開くと動く、**架空の時刻表**を使った乗換検索デモです。

## できること
- 船橋日大前→北習志野→新津田沼→徒歩→津田沼→太東（帰りも対応）
- 千葉・蘇我・上総一ノ宮での別列車への乗換候補の探索（大網と茂原での別列車への乗換は不可）
- 駅ごとの所要時間を設定して検索
- 全乗換時間・駅間徒歩を0分とした理論上の検索
- 設定時間は同じブラウザの `localStorage` に記録

## **重要：実際の通学にはまだ使用しないでください**
現時点で表示する時刻表は100%架空です。実際の列車の発着、直通運転、平日・休日・運休等は反映していません。「0分モード」は物理的に不可能な接続も含みます。駅構内を走る前提で使用しないでください。

## 起動方法
`index.html` をスマホやPCのブラウザで開きます。ファイルのプレビューではスクリプトをブロックする場合があるので、表示できないときは普通のブラウザで開くか、GitHub Pages でホストしてください。

## 次の実装タスク（Codex向け）
1. ダミー時刻生成と経路探索のロジックを別モジュールに分ける
2. 現行ダイヤの正規データを適法な提供元から収集・更新する仕組みを用意する（利用規約・データライセンスを確認）
3. 平日・土休日・日付指定で運行ダイヤを選択できるようにする
4. JRの総武快速・総武線各駅停車・外房線、東葉高速線、京成松戸線の直通や行先・停車駅を検証する
5. 検索結果に乗車列車の識別子・乗り場情報（入手可能なら）・データ更新日を表示する
6. 乗換候補の安全な余裕時間と0分理論値の区別を徹底する
7. データ検証や経路探索の自動テストを整備する
8. 通学経路の他の実用的な乗換パターンについて利用者に確認する

## 技術
HTML + CSS + JavaScript。外部ライブラリ・API不要、通信不要。現時点では架空時刻による路線探索です。実際のAIエージェント機能は**まだ実装していません**。
